# Space Museum — Abandoned But Not Forgotten

An interactive 3D educational experience exploring the stories of humanity's abandoned lunar and Martian exploration hardware.

## About the Project

Space Museum is a virtual museum where visitors can explore historical spacecraft, discover NASA mission archives, interact with robotic spacecraft characters, and learn about the engineering achievements behind each mission.

Meet Lumi, our robotic museum guide, and explore the forgotten stories of human space exploration.

## Key Features

- Interactive 3D virtual museum
- Nine historical lunar and Martian exhibits
- Interactive mission storytelling
- Robotic museum guide Lumi
- Historical mission timeline
- Interactive 3D exhibit inspection

## Technologies

- JavaScript
